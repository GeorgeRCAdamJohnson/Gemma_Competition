What the forum changed in the earlier read

The scorer runs the hidden tasks one at a time. Kernels at 4 to 8 in flight slowed each sequence from about 30 to 23 tokens per second, so the timeout rate on those runs is worse than the board. The 10-minute gain will be smaller there than 19 versus 9. It is still the pack to submit, because the combined config did not add task-time.
Compaction thresholds are not host-confirmed. The Getting Started notebook uses a 14,336-token threshold. A competitor says the scorer also uses interval 5 and keeps 5 events. Submissions cannot set either. The summarizer keeps only text, so a tool-only trace is what gets forgotten.
A context overflow skips the git-diff fallback: 44 of 44 overflowed sessions submitted an empty patch, 14 of them after a successful edit. Timeout and call-limit paths still capture the diff. A longer cap that overflows the window throws away the edit the extra time just bought.
